# Support

AgentGitOps is community-supported open-source software.

- Use [GitHub Issues](https://github.com/terrymyth/agentgitops-open/issues) for reproducible bugs and scoped feature requests.
- Use [GitHub Discussions](https://github.com/terrymyth/agentgitops-open/discussions) for usage questions, design proposals, and community help.
- Use [Private Vulnerability Reporting](https://github.com/terrymyth/agentgitops-open/security/advisories/new) for suspected security vulnerabilities. Never disclose a vulnerability in a public issue.

Support is best effort and does not include an SLA. Before posting logs, remove credentials, private repository URLs, customer data, local usernames, and absolute paths. Commercial support or private modules, if offered later, will be documented separately and will not reduce the rights granted for code already published here.
